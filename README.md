# rebirth-noise

Когерентный шум на безопасном Rust: value, Perlin, simplex, cellular, фракталы и заполнение объёмов.

Переписано с нуля на Rust по идее проекта **FastNoiseSIMD** (Jordan Peck, MIT): https://github.com/Auburn/FastNoiseSIMD. Это не порт и не перевод кода: реализация написана заново по опубликованным алгоритмам, авторство идеи и лицензия оригинала сохранены (см. LICENSE).

## Что внутри

- Четыре вида шума: `Value`, `Perlin`, `Simplex` (2D и 3D), `Cellular` (Ворлей) с возвратом F1, F2, F1+F2, F2−F1, F1·F2 и значения ячейки;
  метрики: евклидова, манхэттенская, Чебышёва; настраиваемое смещение центров.
- Фракталы: `Fbm`, `Billow`, `Rigid` (с обратной связью между октавами), октавы, лакунарность, усиление.
- Хэш координат: арифметика из умножений и сдвигов, без таблиц перестановок.
- Заполнение 2D-буфера и 3D-объёма (`fill2`, `fill3`).
- Всё в диапазоне `[-1, 1]`, детерминированно: одно зерно и координаты дают один и тот же ответ на любой машине.
- `#![forbid(unsafe_code)]`, ни одной зависимости.

```rust
use rebirth_noise::*;
let mut n = Noise::new(Kind::Simplex, 42);
n.octaves = 5;
n.frequency = 0.02;
let h = n.get2(100.0, 200.0);
assert!((-1.0..=1.0).contains(&h));
```

## Замеры

`cargo run --release --example bench -p rebirth-noise`. Объём 128³, одна октава, один поток, скалярная арифметика (SIMD нет).

| шум | Мзначений/с |
|---|---|
| Value | 46,8 |
| Perlin | 39,5 |
| Simplex | 28,5 |
| Cellular | 5,7 |
| Simplex fBm, 5 октав | 4,0 |

FastNoiseSIMD написан на SIMD (AVX2/AVX-512/NEON) и по скорости на порядок быстрее; эта библиотека выбирает переносимость и
безопасность, а не скорость, и с ним на скорость не соревнуется.

## Проверка

Восемь тестов: детерминизм и влияние зерна; все виды и фракталы остаются в `[-1, 1]` и не вырождаются в константу;
непрерывность (малый шаг даёт малое изменение); нули Перлина в узлах решётки; F1 ≤ F2 и постоянное значение внутри ячейки;
правильная сетка при нулевом смещении; `fill` совпадает с поточечным расчётом; большие и отрицательные координаты.
